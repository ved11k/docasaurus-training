# Post-Installation Setup

After installing the banking application, complete the following steps before using it.

## Configure the Application

1. Launch the banking application.
2. Enter the server URL provided by your administrator.
3. Select your preferred language.
4. Save the configuration.

## Verify the Connection

1. Open **Settings > Connection**.
2. Select **Test Connection**.
3. Verify that the connection status shows **Connected**.

## Complete Security Setup

- Change the default password.
- Enable multi-factor authentication (MFA).
- Configure the session timeout.
- Verify your registered email address.

## Verify the Installation

Sign in to the application and confirm that the dashboard loads successfully.

> **Note:** Contact your system administrator if you cannot connect to the banking server.
