# Troubleshoot Transaction Failures

Use the following solutions if a fund transfer or payment fails.

## Transaction Failed

**Possible causes:**

- Insufficient account balance
- Incorrect beneficiary details
- Network connectivity issue
- Bank server unavailable

**Solution:**

1. Check your account balance.
2. Verify the beneficiary details.
3. Check your internet connection.
4. Wait a few minutes and retry the transaction.

## Amount Debited but Transaction Failed

If the amount is debited but the transaction fails:

1. Check the transaction status in **Transaction History**.
2. Wait for the automatic reversal.
3. Contact customer support if the amount is not reversed.

> **Note:** Keep the transaction ID available when contacting customer support.
