# Glossary

This glossary defines common terms used in the banking application.

| Term | Definition |
|---|---|
| **Beneficiary** | A person or account that receives a fund transfer. |
| **IFSC** | A code used to identify a bank branch in India. |
| **NEFT** | A system used to transfer funds between bank accounts. |
| **RTGS** | A system for transferring high-value funds in real time. |
| **IMPS** | An instant fund transfer service available 24/7. |
| **UPI** | A payment system for instant bank-to-bank transactions. |
| **OTP** | A one-time password used to verify a transaction or login. |
| **MFA** | A security method that requires more than one verification method. |
| **Fixed Deposit (FD)** | A deposit held for a fixed period at a specified interest rate. |
| **Transaction ID** | A unique number used to identify a banking transaction. |
| **Available Balance** | The amount currently available for withdrawal or transfer. |
| **KYC** | A process used by banks to verify a customer's identity. |
