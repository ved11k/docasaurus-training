# Supported Environments

The banking application supports the following environments.

## Operating Systems

- Windows 10 and Windows 11
- macOS 13 or later
- Android 12 or later
- iOS 16 or later

## Supported Browsers

- Google Chrome – latest two versions
- Microsoft Edge – latest two versions
- Mozilla Firefox – latest two versions
- Safari – latest two versions

## Network Requirements

- Stable internet connection
- HTTPS connection enabled
- Minimum recommended speed: 5 Mbps

## Screen Resolution

- Minimum: 1280 × 720
- Recommended: 1920 × 1080

> **Note:** For security and compatibility, use the latest supported operating system and browser versions.
