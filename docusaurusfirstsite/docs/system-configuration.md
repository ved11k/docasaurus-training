# System Configuration

This section describes the basic system requirements and configuration needed to use the banking application.

## System Requirements

- **Operating System:** Windows 10 or later
- **Browser:** Latest version of Chrome, Edge, or Firefox
- **RAM:** Minimum 4 GB
- **Internet:** Stable broadband connection

## Browser Configuration

- Enable JavaScript.
- Allow cookies for the banking application.
- Enable pop-ups for downloading statements and receipts.

## Security Configuration

- Enable multi-factor authentication (MFA).
- Use a strong account password.
- Configure automatic session timeout.
- Keep your browser and operating system updated.

## Recommended Settings

For better performance and security:

- Use the latest supported browser version.
- Avoid accessing the application over public Wi-Fi.
- Log out after completing banking activities.
